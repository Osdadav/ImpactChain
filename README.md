# ImpactChain

A social impact contribution tracking and reward platform on Stacks blockchain. ImpactChain enables organizations and individuals to measure, track, and reward positive social impact contributions transparently.

## Features
- Social impact contribution tracking
- Multi-initiative support with registration workflows
- Transparent impact assessment rounds
- Reward distribution based on impact contribution
- Contributor impact status queries

## Getting Started
Establish the impact network, register initiatives, and start recording contributions to earn impact rewards.
